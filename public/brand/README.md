# NoteClaw brand files

| File | Use |
|---|---|
| `logo.svg` | Paw-and-pen mark (vector, traced from the original logo), shown on a white tile in the top bar |
| `icon.svg`, `favicon-32.png` | Browser tab icon |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | Installed-app icons (see `../manifest.webmanifest`) |
| `logo-wide.svg`, `logo-wide.png` | Mark + NOTECLAW wordmark (Luckiest Guy) for README and sharing |

The wordmark letters are outlines, so the files do not need the font installed.
